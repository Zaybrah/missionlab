    Which map file belongs to which mission?
    • Clean House (Suburb): suburbv2.bytes
    • Depot Mexico: depotraid1.bytes
    • Any other mission: host it once with MissionLab installed. The banner at the top left of the game names the file, and so does missions/last.json.

    How it went

      What happened

        Blue is a player, red an enemy; a filled red dot has noticed the players. Lines show the last half minute. Click an event to jump to it. The replay is drawn on the 2D map.

        Enemies

          No enemies yet. Choose Add enemy above the map and click on walkable ground.

          Squads

          Amber markers are the mission's intel items. Drag one to move it; in 3D you can put it on a table or shelf. The game lays each item in one of a few places, a different one each mission; an item you move always lies where you put it.

          Intel items

            Things

            Weapons and other things the game can lay on the ground for every player. Pick one, choose Add thing and click the map. Seen to work in the game: rifles, which can be picked up and used.

              Doors show up here once the editor knows where they are: connect to the game during a mission, or open a recon file written after one mission on the map.

              Doors

              Thick lines on the map are doors. Choose Select and click one to lock or unlock it. The game locks some doors by chance, different ones each mission; a door you set is always as you set it.

                Triggers

                  When a trigger fires, the enemies bound to it appear and its doors lock or unlock. For a zone, choose Add zone and click the map. Bind an enemy by selecting it and setting "Appears"; give a trigger a door by selecting the door.

                  Waves

                  Enemies that walk in on one spot, wave after wave, for holding a building. The spot is the selected enemy, or else the middle of the map view.

                  Mission check

                    Mission

                    Extraction: the mission's own rule still applies; this only holds it back until a trigger has fired. Rain, sandstorm and hour only work on maps that have weather; Clean House, Mexico Depot and Georgia do not.

                    Try-outs

                    One-click experiments while a mission runs. Each asks the game for one thing and reports what happened. They are not finished features; the ones that work get a proper place later.

                    Selected enemy

                    A trigger can wait until the enemies with a tag are down. Skill was applied in a run, but one enemy more or less sharp is hard to notice: the Mission tab can set it for all of them.
