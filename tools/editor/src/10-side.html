                Map

                Example map

                Dark lines are borders nobody can cross: walls, fences, furniture. For real walls and furniture in the 3D view, also open the .mlgeo file that Game Master mode exports into BepInEx/MissionLab/maps (press M there). Open a map file from OPERATOR/OPERATOR_Data/NavMeshData. You can also open a scenario, a mission record from BepInEx/MissionLab/missions, or a recon file to see insertion points. Files stay on your computer.

                Which map file belongs to which mission?
                • Clean House (Suburb): suburbv2.bytes
                • Depot Mexico: depotraid1.bytes
                • Any other mission: host it once with MissionLab installed. The banner at the top left of the game names the file, and so does missions/last.json.

                Quick mission

                MissionLab's generator makes a layout on a map: Generate shows it on the map, Reroll tries another seed, Keep opens it here as a new scenario to change and save.

                The quick mission needs the game: the generator reads the map's own navigation file in your OPERATOR folder, which MissionLab never copies. Start OPERATOR with MissionLab and open http://localhost:8765.

                Shares, not counts. All three at 0: the generator's own mix, with more guards indoors.

                Moved intel is not offered: it needs the game itself and the RandomIntel setting, so the intel stays where the game puts it.

                  Places

                  Names for parts of the map, such as Rear stairs or Upstairs office. Triggers, the mission check and replays then say where something is in words. A point place covers 3 m around its pin on its floor; an area place is painted.

                      Replay

                      How it went

                        What happened

                          Blue is a player, red an enemy; a filled red dot has noticed the players. Lines show the last half minute. Click an event to jump to it. The replay is drawn on the 2D map.

                          Debrief

                          Facts from the recording only: each number names the event or record it was counted from, and older recordings mark their guesses. Health, shots fired and players' use of doors are not recorded, so they are never given.

                                        Modules
                                        
    
                                        A module is a whole encounter kept for reuse: the selected enemies, their routes, the triggers that bring them and what those wait for, with their messages. It is measured from the selected enemy, so it can go anywhere, turned, on this map or another. Doors, intel items, named places and triggers outside it are asked for when it is put in.

                                                    Sealed
                                                    
    
    
                                                    For a host who wants to discover the mission with the squad. This is spoiler avoidance, not secrecy: the file stays readable, and Create asks before it shows a sealed mission's enemies. A reveal lasts until the page is reloaded; another tab starts sealed.
                                                    
  
                                                    

  
                                                    
    
                                                    Host options 
                                                    
    
                                                    Choices the host makes before the mission, such as how many guards or how many reinforcement waves. A choice can drop enemies of a lot, switch triggers off, and set waves and enemy skill. Name choices for what they do; how hard one plays is your suggestion until it has been measured.
                                                    
    
                                                      
    
                                                      
      
      
    
                                                      
    
                                                      
    
                                                        
  
                                                        

  
                                                        
    
                                                        Game Master budget
                                                        
    
                                                        Action cards for whoever directs the mission: each fires one of your triggers, costs points and rests for a while. The game checks every card itself, whichever page plays it; the host may turn the budget rules off for a session.
                                                        
    
    
                                                        
      
                                                        
      
                                                        
      
                                                          
      
                                                          Add a trigger first: every action fires one. A trigger that waits for nothing ("After another trigger" with none chosen) fires only by hand, which suits a card best.

                                                                        Packs
                                                                        
    
                                                                        A pack is one file to give to other players: this scenario, and modules if you like, with a list of what it needs (the map file, PvE, the MissionLab version and the features it uses). It never holds the game's map data, geometry or replays: each player's own game supplies the map.
                                                                        
    
                                                                        Export pack
                                                                        
    
                                                                        
    
                                                                          
    
                                                                          
      
      
      
    
                                                                          
    
                                                                          
    
                                                                          Import pack
                                                                          
    
                                                                          Opening a pack shows everything in it first; nothing is installed until you choose to, and nothing is ever written over.
